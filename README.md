# ملف إنجاز المعلمة

موقع ملف الإنجاز مرتب على بنود بطاقة تقييم ملف إنجاز المعلمة 1448هـ (26 بندًا).

## إضافة شاهد

1. افتحي فولدر `files` ثم فولدر رقم البند (الجدول تحت).
2. اضغطي **Add file ← Upload files**، واختاري الصور أو ملفات PDF أو Word أو الفيديو.
3. اضغطي **Commit changes**. الموقع يتحدث خلال دقيقة أو اثنتين.

- اسم الملف هو اللي يظهر في الموقع، فسمّيه اسم واضح، مثلاً: `تقرير اليوم الوطني.pdf`.
- الصور بتظهر مصغرة وتتكبر لما تضغطي عليها.
- أقصى حجم للملف من المتصفح 25 ميجا. الفيديو الكبير ارفعيه على YouTube أو Drive وضيفيه كرابط.

## وصف الشاهد

في فولدر البند اعملي ملف اسمه **`وصف.txt`** (Add file ← Create new file)، واكتبي فيه:

```
اسم النشاط / الاستراتيجية:
الصف والتاريخ:
وصف النشاط وكيف حقق البند:
نتائج الطالبات:
تعليقي وتغذيتي الراجعة:
```

الوصف بيظهر فوق ملفات البند.

## روابط (Drive، YouTube، منصات)

في فولدر البند اعملي ملف اسمه **`روابط.txt`**، وكل سطر فيه اسم ثم الرابط:

```
فيديو الدرس النموذجي | https://youtu.be/...
عرض الاستراتيجية | https://drive.google.com/...
```

ملفات Drive لازم تكون مشاركة «أي شخص معه الرابط».

## بياناتك وصورتك

- الاسم والوظيفة والمدرسة والنبذة في ملف `config.json` (افتحيه واضغطي القلم للتعديل).
- الصورة الشخصية: ارفعي صورة اسمها `photo.jpg` في الصفحة الرئيسية للمستودع.
